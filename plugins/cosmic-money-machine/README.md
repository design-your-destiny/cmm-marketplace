# Cosmic Money Machine

For members of *Design Your Destiny: The Profitable Coach*.

The Cosmic Money Machine takes your four finished Keeper Statements and the rough Magic Model sketch from your coaching, sharpens them into a finished model, builds your offer from it, creates content to attract your people, and gives you a Sacred Code to keep and reuse.

## Install

1. In Claude (Pro or higher), open **Customize**, then **Plugins**.
2. Select **Add**, then **Add marketplace**, and enter `design-your-destiny/cmm-marketplace`.
3. Install **Cosmic Money Machine**, and turn on **Sync automatically** so you always have the latest version.
4. Make sure code execution is turned on in your Claude settings. The studio uses it to build your Magic Model diagram link and your printable one-sheet.

## Start a session

Start a new chat and type `/cmm`, or simply say: "Let's start my Cosmic Money Machine session."

Have your four Keeper Statements and your Magic Model sketch ready.

## Your work between sessions

Claude doesn't carry your work from one chat to the next. At the end of a session, save your **Sacred Code**, then paste it into your next chat to pick up where you left off.
