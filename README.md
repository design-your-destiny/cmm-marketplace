# Design Your Destiny: Claude Plugins

Tools for members of *Design Your Destiny: The Profitable Coach*.

## Cosmic Money Machine

Takes your four finished Keeper Statements and your Magic Model sketch from coaching, sharpens them into a finished model, builds your offer from it, creates content to attract your people, and gives you a Sacred Code to keep and reuse.

## Install (Claude Pro or higher)

1. In Claude, open **Customize**, then **Plugins**.
2. Click **Add**, then **Add marketplace**, and enter: `design-your-destiny/cmm-marketplace`
3. Find **Cosmic Money Machine** and click **Install**.
4. Turn on **Sync automatically** for this marketplace so you always have the latest version.

Then start a new chat and type `/cmm`.
